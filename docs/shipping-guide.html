Shipping an order

What to do when an order needs to be mailed to the customer — not picked up in person.

🔌 One-time setup: connect ShipStation

Before any of this works, someone needs to enter the studio's ShipStation login once: go to Settings → Shipping Providers, enter the API Key and API Secret from the ShipStation account, then click Save. If this is already set up, skip ahead to Step 1.

Before you start: is this a test order or a real order?
🧪Test order (practice, training, nobody really ordered this) → in Step 3, click Test Label. Doesn't cost anything — if a free test isn't available, the app buys the label and cancels it right away, which refunds automatically.
🚀Real order (an actual customer paid for this) → in Step 3, click Buy Label. Buys a real, paid label with a real tracking number.
⚠️ Both mark the order Shipped in PhotoDay — Test Label just uses a fake tracking number instead of buying anything. Never click either one on a real order you don't actually want marked as shipped.
1
Open the order

Find it in the Live Queue and click anywhere on its row. Orders waiting to ship just show ⏳ Pending — the shipping buttons only appear once you open the order.

2
Click "Ready to Ship"

This green button shows up on the order screen for anything that isn't a walk-in pickup. Clicking it doesn't ship anything yet — it just opens the box in Step 3.

3
Check the weight, then pick a button

A normal weight fills in by itself — leave it as-is unless this order is unusually heavy (a large or bulk print order). Then pick one of the buttons below it:

Buy Label — real order. Buys an actual paid label with a real tracking number, and marks the order fulfilled. Skip to Step 4.
Test Label — practice run. Opens one more box (below), prints a label at no cost to you, and marks the order fulfilled with fake tracking.
Print Test Label — just checking the printer, nothing else. Doesn't touch PhotoDay or the order at all.

If you clicked Test Label, a carrier and tracking number box opens, already filled in with UPS and TEST1234 — leave those as-is (or change them) and click Confirm Shipped. A label prints right then too, so this doubles as a printer check.

Just want to check the printer without touching the order at all? Click Print Test Label instead — same kind of label, but nothing gets marked shipped.

💡 If either one ever shows a warning that a real charge couldn't be refunded automatically, that's not something to fix yourself — just let whoever manages your ShipStation account know so they can check it there.

4
Print it and attach it to the package

After Buy Label, the real label opens by itself and the print window pops up. Print it, tape it to the box — that's it. The order now shows Shipped.

💡 Closed the print window by accident? Reopen the order — a Reprint Label button appears next to Ready to Ship any time a real label has already been bought, so you can print it again without buying a new one.
⚠️ If "Ready to Ship" doesn't work

Once in a while the automatic label can't be created. If that happens, do it by hand instead: click Mark Shipped, pick the carrier, then type in the tracking number from the label. Confirm Shipped stays grayed out until both are filled in, so there's no way to accidentally confirm the wrong thing.
