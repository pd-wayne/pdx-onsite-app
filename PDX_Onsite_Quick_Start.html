PDX Onsite — Staff Guide

Quick Start

Everything you need to run the pickup station at an onsite event.

1 First Launch (one-time setup)
  1. Double-click PDX_Onsite.exe — a browser window opens automatically at localhost:5050.
  2. You'll land on Settings. Enter your Lab ID and API Key (provided by your PhotoDay account manager).
  3. Click Test Connection — it should show a green checkmark and pending order count.
  4. Set the Image Output / Hot Folder to the folder your DNP printer watches (e.g. C:\DNP\HotFolder\Prints). Click Browse… to pick it.
  5. Choose your Printer from the dropdown (should auto-detect the Epson TM-M30II for receipts).
  6. Set Fulfillment Mode → Pickup Only for onsite events.
  7. Click Save Settings. The app polls immediately and orders appear in the queue.
Settings save next to the .exe and persist across restarts — you only do this once per machine.
2 Daily Startup
  1. Double-click PDX_Onsite.exe.
  2. Check the top status bar — the dot should be green (Connected) and you'll see pending/total order counts.
  3. Orders start populating automatically. No other action needed.
If the dot is amber (No credentials) or red (error), go to Settings and re-check your Lab ID and API Key, then Save Settings again.
3 Live Queue — watching incoming orders
Queue tabShows all incoming orders. New orders appear automatically — no refresh needed.
Status chips ⏳ Pending waiting to print   🖨 Printed images sent to DNP   ✓ Completed customer picked up
Needs Attention⚠ Needs Attention order has been waiting longer than the threshold (default 30 min). Use the filter dropdown to show only these.
Filter by JobUse the search box in the left sidebar to filter the queue to one specific event/gallery. Click All Jobs to go back to all orders.
View detailClick any row (or the View button) to see order items, images, and action buttons in a slide-out panel.
4 Print Modes
Auto (recommended)Images download to the hot folder the moment an order arrives. The DNP printer fires automatically. Nothing to click.
ManualImages don't download until you open an order and click Send to Printer. Use this when you want to control when each order prints.
Send to PrinterIn manual mode (or to reprint), open an order detail and click 🖨 Send to Printer. The button is disabled once already sent.
Reprint ImagesClick 🔁 Reprint Images in the order detail to resend images to the hot folder (for reprints / rejects).
Reprint ReceiptClick 🧾 Reprint Receipt to re-print the ESC/POS receipt to the Epson printer.
5 Scan to Confirm Pickup
  1. Click 📷 Scan to Confirm in the left sidebar.
  2. Scan the QR code on the customer's receipt, or type the order number manually.
  3. The field turns green with the customer name. Click Mark Ready for Pickup (or press Enter).
  4. The order moves from the queue to Completed. The status bar count updates instantly.
Recent completions appear below the scan box so you can see what was just confirmed.
If the scan shows "already completed" — the customer's order was previously confirmed. Check the queue history or search for the order number.
6 Search
  1. Click the search bar at the top of the screen.
  2. Type any part of an order number, customer name, or image filename.
  3. Results appear as cards — click any to open the order detail.
  4. Press Escape or click ✕ to clear the search.
7 Samples Browser
  1. Click 🖼 Samples in the sidebar.
  2. Click Browse Folder to pick a folder of display/sample images.
  3. Click thumbnails to select them (or Select All).
  4. Click 🖨 Print Selected to send them to the DNP printer.
You can configure the Samples Folder path in Settings so it loads automatically on startup.
8 Quick Troubleshooting
No orders showingCheck the status bar — is it green? If not, go to Settings → Test Connection. Also check Fulfillment Mode is set correctly (Pickup Only for onsite events).
Images not printingCheck that the Image Output folder in Settings points to the actual DNP hot folder. Open an order and look for a ⚠ download error icon.
Receipt not printingGo to Settings → Printer, confirm the Epson TM-M30II is selected. Click ↻ to re-detect printers.
Status bar is amber"No credentials" — go to Settings, re-enter Lab ID and API Key, Save Settings.
Browser closed by accidentNavigate to localhost:5050 in any browser — the app is still running in the background.
App won't startCheck if another instance is already running (look in the Windows taskbar). Only one copy can run at a time.
Poll NowClick the ↻ Poll Now button in the top bar to force an immediate check for new orders.
